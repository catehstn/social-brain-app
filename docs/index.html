Platform Setup Guide

API Key Platforms

For these platforms, go to the platform's settings page and create or copy an API key, then paste it into Social Brain's Platforms screen.

API Key

Buttondown

Go to buttondown.com/settings/api → copy your API key.

API Key

GoatCounter

Go to Settings → API tokens in your GoatCounter dashboard and create a new token with read access.

You'll also need your site code (the subdomain part of your GoatCounter URL).

API Key

Calendly

Go to Calendly → Integrations → API & Webhooks → generate a Personal Access Token.

API Key

Amazon KDP

Amazon KDP doesn't have a public API. Use the File Export method instead — see below.

Access Token / App Password Platforms

Token

Mastodon

  • Go to your Mastodon instance → Settings → Development → New application
  • Give it read permissions; copy the access token.
  • Also enter your instance URL (e.g. mastodon.social).
Token

Bluesky

  • Go to Settings → Privacy and security → App Passwords
  • Create a new app password — use this instead of your main password.
  • Enter your handle (e.g. you.bsky.social) and the app password.
Token

Jetpack / WordPress.com

  • Go to developer.wordpress.com/apps → create an application.
  • Use the OAuth flow in Social Brain to authenticate — it will open a browser window.
OAuth

Google Search Console

Social Brain fetches clicks, impressions, CTR, average position, and top queries/pages.

  • Go to console.cloud.google.com → create a new project (or select an existing one).
  • Enable the Google Search Console API in APIs & Services → Library.
  • Go to APIs & Services → Credentials → Create Credentials → OAuth client ID.
  • Choose Desktop app as the application type. Copy the Client ID and Client Secret.
  • Run the OAuth flow once to get your access token and refresh token:
    Use OAuth 2.0 Playground, select https://www.googleapis.com/auth/webmasters.readonly, and enter your own client ID/secret under the gear icon.
  • Enter your site URL exactly as it appears in Search Console (e.g. https://example.com/ or sc-domain:example.com).

File Export Platforms

These platforms don't offer API access. Download a fresh export and drag it into Social Brain's Platforms screen.

File Export

Substack

  • Go to your Substack dashboard → Settings → Exports
  • Request a data export; download the ZIP and find subscribers.csv.
File Export

Amazon KDP

  • Go to KDP Reports → Royalty
  • Download the Prior Months Royalties TSV for the current month.
File Export

LinkedIn

  • Go to your LinkedIn profile → Analytics → Post impressions
  • Click Export to download a CSV.
File Export

O'Reilly

  • Log in at oreilly.com → Account → Monthly Report
  • Download the TXT report for the most recent month.
